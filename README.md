# Intelligent Inclusive Navigation System

Source code accompanying the paper:

"Intelligent Inclusive Navigation System for a University Digital Ecosystem"

## Components

- QR code localization (Pyzbar)
- Object detection (SSD MobileNet V3)
- TFmini-S LiDAR integration
- A* route planning
- Voice command recognition (VOSK)
- Audio navigation guidance

## Hardware

- Raspberry Pi
- Sony IMX708 Camera
- TFmini-S LiDAR
- OLED Display

## Installation

pip install -r requirements.txt

## Run

python main.py
